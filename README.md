# Grace Community Church

Marketing website for Grace Community Church — a single-page React app with pages for Home, About, Leadership, and Resources.

## Tech

Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui. Tested with Vitest (unit) and Playwright (e2e).

## Run locally

```bash
npm install
npm run dev          # http://localhost:8080
```

## Other scripts

```bash
npm run build        # production build
npm run preview      # serve the production build
npm run lint         # eslint
npm test             # unit tests
npm run test:e2e     # build + Playwright
```
